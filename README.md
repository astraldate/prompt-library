# Prompt Library (悬浮球提示库)

一个轻量级的桌面悬浮球应用，用于快速管理、检索和粘贴常用的 AI Prompt（提示词）。基于 Tauri + React 构建，占用资源极少，支持 Windows 平台。

## ✨ 主要功能

*   **悬浮球交互**：桌面常驻一个小球，点击展开，拖拽移动。
*   **一键粘贴**：左键点击 Prompt，自动复制并粘贴到当前光标所在位置（如 ChatGPT 输入框、代码编辑器等）。
*   **右键编辑**：右键点击 Prompt 即可快速修改内容。
*   **全局快捷键**：按下 `Alt + Space` 快速显示/隐藏悬浮球。
*   **Prompt 管理**：支持添加、删除、搜索 Prompt，支持收藏常用 Prompt。
*   **开机自启**：可在设置中开启开机自动启动。
*   **本地存储**：所有数据存储在本地 AppData 目录，安全且隐私。

## 📖 操作手册

### 1. 基础操作
*   **展开/收起**：点击悬浮球可展开面板；点击面板底部的“收起”按钮或再次点击悬浮球可收起。
*   **移动位置**：按住鼠标左键拖拽悬浮球或面板顶部的标题栏，即可将其移动到屏幕任意位置。位置会自动记忆。

### 2. 使用 Prompt
*   **复制并粘贴**：在列表中**左键单击**任意 Prompt，窗口会自动隐藏，并将 Prompt 内容粘贴到你当前光标停留的地方。
*   **预览内容**：将鼠标**悬停**在 Prompt 标题上，会显示完整的 Prompt 内容。

### 3. 管理 Prompt
*   **添加**：点击顶部的 `+` 号按钮，输入标题和内容即可添加。
*   **编辑**：在列表中**右键单击**任意 Prompt，即可进入编辑模式。
*   **删除**：点击 Prompt 右侧的垃圾桶图标 🗑️ 删除。
*   **收藏**：点击 Prompt 右侧的星星图标 ★ 加入/取消收藏。在“Favorites”标签页可仅查看收藏项。
*   **搜索**：在顶部搜索框输入关键词，实时过滤 Prompt。

### 4. 快捷键
*   **Alt + Space**：全局显示/隐藏悬浮球。无论你在哪个应用界面，按下此快捷键都能快速呼出。

## 🛠️ 技术栈
*   **Core**: [Tauri v2](https://tauri.app/) (Rust)
*   **Frontend**: React + TypeScript + Vite
*   **State**: React Hooks + Local FS

## 📦 安装与构建

1.  克隆仓库
2.  安装依赖：`pnpm install`
3.  开发模式：`pnpm tauri dev`
4.  构建发布：`pnpm tauri build`
